Dynamic Memory for Claude

Claude Skill · Prompt Eng.

View on GitHub →

A memory skill that makes Claude a long-term collaborator — one that understands personal shorthand and remembers everything it's been told, across conversations.

The Problem

Without memory, shorthand is meaningless. Tell Claude "ping J about Horizon before standup" in a fresh conversation and it has no idea who J is, what Horizon refers to, or when standup happens — all context that a real assistant would already know.

The Solution

Dynamic Memory is a Claude Skill that gives Claude a persistent, on-disk memory: contacts, preferences, projects, and any other category it decides is worth tracking, created on the fly rather than hardcoded in advance.

It's built as a two-tier store — a hot cache (memory/cache.md) for fast lookups, backed by deep storage in the memory/ directory, with disk as the source of truth so multiple conversations can share the same memory. The design is inspired by the memory component of Anthropic's Productivity plugin, extended with dynamic (not predefined) categories and a hot cache kept separate from CLAUDE.md.

This repo is continuously evolving as I add new features and improvements to reduce token usage and improve efficiency.
